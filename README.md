### Overview
C++ project to demonstrate git commands and usage

### Build Instructions
Compile the Project
g++ src/main.cpp -o app
Run the Executable
./app

On Windows:

app.exe
Example Output
Hello, World!

Cleaning Build Files

Remove generated executable:

rm app

## Troubleshooting
Command Not Found: g++

Install G++:

Ubuntu/Debian:

sudo apt update
sudo apt install g++
Permission Denied

Grant execute permissions:

chmod +x app
Compilation Errors
Verify compiler installation.
Check for syntax errors.
Ensure all header files are included correctly.
Rebuild the project after making changes.
